# 大模型训练互动导览 · whatsAI

面向没有机器学习基础、具备初中及以上阅读能力的读者，用约 10–15 分钟走过数据准备、预测、参数更新、连续训练与模型比较。主线运行一个浏览器本地的微型字符语言模型，无需 API 密钥或远程推理服务。

项目希望让好奇的读者看到“训练”具体在做什么。它是持续修订中的学习型原型，使用小模型解释部分训练机制，不复现完整的大语言模型系统。制作动机、设计取舍和迭代经验见 [项目说明](./项目说明.md)。

## 体验内容

| 章节 | 可以做什么 |
| --- | --- |
| 概念地图 | 独立组合模型方向、训练阶段和学习方式，查看对应业务案例及不常见组合的解释；包含具身智能场景 |
| 准备数据 | 查看原始句子、去重结果、字符编号，以及“前文 → 下一字”的训练样本 |
| 一次训练 | 查看预设结构和初始参数，逐步执行预测、计算损失、计算梯度、更新参数 |
| 反复迭代 | 调整学习率、批次大小和训练步数，查看日志、训练与验证损失曲线 |
| 比较与测评 | 比较不同检查点和实验，用选中的模型生成文字，导出模型参数 |
| 后训练与分支 | 查看 SFT、偏好优化、强化学习，以及图像与多模态的流程示意 |

主线概率、损失、梯度和参数更新来自实际计算；典型曲线教学示例、后训练和图文分支使用标注过的示意或预设结果。后者不执行相应模型的训练。

## 技术实现

- **界面：** React 19 + Vite，中文解释、可点击术语、简化的工程师工作台。
- **模型：** JavaScript 实现的前馈字符网络：4 个字符的上下文 → 8 维字符嵌入 → 24 个 `tanh` 隐藏单元 → `softmax` 下一字概率。当前词表 88 项，共 3,696 个可训练参数，不是 Transformer。
- **训练：** 交叉熵损失、手写反向传播、随机抽样小批次梯度下降。验证数据不用于参数更新；生成文字也不改变参数。
- **数据：** 内置短句；默认去掉空白和重复项后，32 句训练文本、6 句验证文本。仅用于教学，不代表通用语言能力评测。
- **保存：** 训练状态、检查点和实验记录保存在当前页面内存，刷新会重置；可下载参数 JSON，页面尚不支持导入模型或完整恢复训练。

## 本地运行与构建

使用 Node.js 22.12 或更高版本，以及 Git：

```bash
git clone https://github.com/yidanzhu35-a11y/whatsAI.git
cd whatsAI
npm ci
npm run dev
```

打开终端显示的本地地址。需要固定为本项目常用预览地址时，使用 `npm run dev -- --host 127.0.0.1 --port 4174 --strictPort`。

```bash
npm test
npm run build
npm run preview
```

静态站点产物在 `dist/client/`。构建也会生成用于 Sites 部署的 `dist/server/index.js` 和 `dist/.openai/hosting.json`。

构建完成后，运行 `node scripts/export-standalone.mjs`，可在仓库上一级生成 `model-training-tour.html`。该文件内置脚本、样式与教学数据，模型计算在访问者浏览器中完成。

## 页面批注与文本编辑

这两个模块用于评审和修改页面内容：

- **批注：** 点击右下角「批注」，选择文字、界面元素或整章，记录意见；支持定位、编辑、处理状态、JSON 备份和 Markdown 清单。保存章节、引用文字及部分选项，不重现完整训练状态。
- **文本编辑：** 点击「文本编辑」，修改带虚线的文案；清空并保存可删除该处文字。改动先作为当前浏览器的显示覆盖，不直接改动源码或训练算法。通过「导出修改清单」导出 JSON，核对并合并到 `src/` 后，再构建和提交，才成为共享版本。`scripts/bake-copy.mjs` 可辅助写回匹配的静态文案，动态文案可能需要手动处理。

| 数据 | 保存与同步方式 |
| --- | --- |
| 本机开发预览的批注 | 通过 `localhost` / `127.0.0.1` 访问 `npm run dev` 时，可写入 `.feedback/comments.json`，同时保留浏览器副本；以面板显示的保存结果为准 |
| 生产网页、构建预览、独立 HTML 的批注 | 只保存在当前浏览器，不自动发送给作者；可导出 JSON 交接或换电脑导入 |
| 文本编辑记录 | 保存在当前浏览器，可导出 JSON；不会自动同步到项目文件或另一台电脑 |

`.feedback/`、`node_modules/` 和 `dist/` 不提交到 Git。跨电脑同步源码使用 Git；批注和尚未合并的文字修改需单独导出。清除浏览器数据前，请先备份这些记录。

## 代码与验证

| 路径 | 用途 |
| --- | --- |
| `src/model.js` | 微型模型、训练数据、前向计算、梯度与生成 |
| `src/` | 六章界面、术语解释、曲线、批注及文本编辑 |
| `scripts/` | 开发批注接口、文案写回、构建和独立 HTML 导出 |
| `tests/` | 模型计算、反馈存储、教学流程数据和部署配置检查 |
| `worker/`、`.openai/hosting.json` | Sites 部署适配 |

自动化测试包含梯度的数值校验、演示训练后的损失变化、推理不改参数，以及批注保存等检查。测试通过不等于所有解释均经过专业审校；欢迎通过 Issue 指出具体页面、问题和参考依据。
