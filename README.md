# 大模型训练互动导览

一个在浏览器里「亲手训练一次语言模型」的中文互动导览，面向初中及以上读者。

它不播放动画，也不调用任何云端接口：一台微型字符模型就在读者自己的浏览器里运行，每一步计算都是真实的数字。读者会从“模型到底是什么”出发，依次走过数据整理、一次参数更新、连续训练、保存比较与亲手生成文字，再进入后训练与多模态、具身智能等分支，检验自己对“训练”与“使用”的理解。全程约 10–15 分钟，不需要 API 密钥，也不消耗任何云端算力。

## 这条导览讲什么

主线是一台极小的字符语言模型：从 4 个字符的前文预测下一个字。规模虽小，训练语言模型的关键环节都在里面。

| 章节 | 内容 |
| --- | --- |
| 概念地图 | 模型类型、训练阶段、学习方式三个维度自由组合，理解这些词为什么能组合、却排不成一棵分类树 |
| 准备数据 | 什么是词表与编号、字符怎样变成数字，并体验一次数据去重与清洗 |
| 一次训练 | 先建立模型结构、填入初始参数，再亲手走完“预测 → 算损失 → 算梯度 → 更新参数”完整一步 |
| 反复迭代 | 设置学习率、批次、步数，观察训练/验证损失曲线与检查点，比较不同实验 |
| 比较与测评 | 保存检查点、导出参数文件，用同一句话比较不同训练时刻的模型，再用选中的模型自由生成文字，理解“使用模型”不等于“训练模型” |
| 后训练与分支 | SFT、偏好优化、强化学习三条改进路线，以及图像、多模态与具身智能扩展 |

页面会明确区分“本机真实计算”与“教学模拟/示意”：真实训练的结果是浏览器算出来的，演示用的预设曲线、流程示意都会标注清楚，不会把演示结果包装成真实结果。

## 设计思路

**用“做一遍”代替“讲一遍”。** 每个抽象概念都被拆成可以在页面上亲手点完的步骤，数字真的在浏览器里算出来。演示先于动作：读者先明白这一步要做什么，再点按钮，看到计算前后发生了什么、哪些参数真的变了。

**概念是维度，不是分类树。** 概念地图用一个主列加三个独立选择维度（模型类型、训练阶段、学习方式），三者可以任意组合，改动一项不会覆盖其他选择；组合会给出它适合做什么的具体案例，也会提示哪些术语需要进一步区分。

**术语在第一次出现处就能解释。** 正文遇到“参数”“损失”“梯度”“隐藏单元”等词，点击即可展开解释，不依赖后面的术语表。解释用平实的中文，并注意把行业惯例、通用规则和本教学自己的选择分开说，让读者逐步获得接近业内人的视角。

**每一页都独立可读。** 页面写作以“读者只看到当前这一页”为前提：不引用旧版本，不依赖后续章节，必要的概念都在第一次出现时讲清楚。

**以批注驱动迭代。** 这是本项目最特别的产品设计，见下一节：评审意见直接落在页面元素上，让内容共创与版本迭代形成一个闭环。

## 在页面上留批注：以评审驱动的产品迭代

读者可以直接在页面文字或界面元素上留意见，不需要截图、标注、来回沟通。批注定位精确到元素，可管理、可撤销、可导出导入，从而支撑“留批注 → 按批注修改 → 标记已处理”的迭代闭环——这是本项目在产品迭代方式上的独特设计。

使用方式：

- 点击页面右下角「批注」，选择「选择页面位置」，然后拖选一段文字或点击按钮、图表等界面元素。写完按「保存批注」，也可用 Ctrl / ⌘ + Enter 保存。选择位置期间，点击按钮不会执行按钮原本的操作；需要先操作页面时，收起批注面板即可。
- 也可以给整章留意见；批注列表支持定位、编辑、标记已处理，以及删除后的即时撤销。它会保存章节、引用原文和部分页面选项；不会重现完整的训练状态。页面内容改变后，定位可能只能到章节。

数据与流转：

- 使用 `npm run dev` 在本机预览时，保存后的批注会写入 `.feedback/comments.json`，同时保留浏览器副本。批注文件不会自动提交到 GitHub；换电脑时点「导出备份」，在另一台电脑的批注面板中导入 JSON，同一编号保留较新的修改。「导出清单」可生成可阅读的 Markdown。
- 发布后的网页或独立 HTML 只把批注保存在当前浏览器，不访问本机文件接口，也不会自动发送给网站拥有者。清除浏览器数据前应先导出备份。
- 保存按钮会等待写入结果，明确显示保存到了项目文件还是仅保存在浏览器。两处均失败时保留编辑内容，不显示保存成功，并在刷新或关闭前提醒；此时可导出备份。历史“使用模型”章节的批注继续保留，定位时进入合并后的“比较与测评”。

## 在新电脑上开始

安装 Node.js 22 和 Git，然后运行：

```bash
git clone https://github.com/yidanzhu35-a11y/whatsAI.git
cd whatsAI
npm ci
npm run dev
```

在终端显示的本地地址打开网页。每次开始工作前执行 `git pull`；修改完成后执行 `git add .`、`git commit -m "说明修改内容"` 和 `git push`。另一台电脑再执行 `git pull` 即可取得更新。两台电脑同时修改同一文件时，Git 可能要求先解决冲突。

## 验证与导出

```bash
npm run build
npm test
node scripts/export-standalone.mjs
```

构建结果在 `dist/`，独立 HTML 会生成在项目文件夹的上一级，文件名为 `model-training-tour.html`。这份 HTML 内置网页代码与教学数据，便于直接分享；模型计算在访问者的浏览器里完成，不消耗仓库拥有者的 API 额度。

`src/` 是网页源码，`src/model.js` 是微型模型及训练计算，`tests/` 是计算和构建验证。`worker/` 与 `.openai/hosting.json` 是可选的 Sites 部署配置。`node_modules/`、`dist/` 等本机生成内容不会提交到 Git。

本项目的微型模型用于解释训练机制，并不等于真实大语言模型的规模或架构。页面会区分实际计算的数值和为了教学展示的模拟步骤。
